# Seivol — English that stays with you

Sitio estático de presentación de Seivol: app de aprendizaje de inglés con práctica personalizada, memoria y apoyo contextual.

## Ver en local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 8080
```

Luego visita `http://localhost:8080`.

## Estructura

- `index.html` — página principal
- `assets/` — CSS, JS e imágenes (`assets/images/`)
